# Task 2: Portrait in the Hall

Every great house has a portrait that watches you walk past. Blackthorn House has one that also runs firmware.

Adrian Vale's likeness hangs in the east hall on a digital frame, smirking at anyone who has ever asked him for a raise. The staff say he fussed over that picture a few nights before the dinner, which is odd behavior for a man who claimed he never looked at it. We pulled the image file straight off the frame. It is in this task's download.

Download the task file and unzip it. You will find:

- `portrait.jpg`, the portrait exactly as the frame stored it

It opens as a perfectly ordinary picture. Adrian did not do ordinary.

A few pointers:

- A picture file carries more than pixels. Read what the file says about itself before you study the brushwork. `exiftool` or any EXIF viewer will do.
- Most of what it says is plain English. One part is not. Adrian wrote it that way on purpose.
- Text that looks like alphabet soup is often just wearing a costume. Work out which one, and take it off.
