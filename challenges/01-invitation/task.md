# Task 1: The Invitation

Welcome to Blackthorn House, investigator. Mind the cobwebs. Some of them are decorative.

Adrian Vale's dinner invitations were printed on very expensive card stock, which is how we know he meant business. One was recovered from the library floor, and a scan of it is in this task's download.

The invitation carries a QR code that pointed guests to a private event page on the house portal. The mansion's network went dark during the lockdown, so that address no longer resolves. Fortunately, the house takes a snapshot of its own portal every night, and we recovered the most recent one. It is in the same download, in a folder named after the portal.

Download the task file and unzip it. You will find:

- `invitation.png`, the scanned invitation
- `portal.blackthorn.thm/`, the portal snapshot

The portal's front page is not in a talkative mood. The invitation knows a better way in.

A few pointers:

- Decode the QR code to see where it sent the guests. The address will not load, but the same path exists inside the snapshot folder.
- Hosts rarely say everything out loud. Read what the page says, then read what it is made of.
- Compare the page against the paper. Paper does not update itself.
