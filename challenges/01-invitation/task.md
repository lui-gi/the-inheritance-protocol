# The Invitation

Welcome to Blackthorn House, investigator. Mind the cobwebs. Some of them are decorative.

Adrian Vale's dinner invitations were printed on very expensive card stock, which is how we know he meant business. One was recovered from the library floor, and a scan of it is the first file attached to this task.

The invitation carries a QR code that pointed guests to a private event page on the house portal. The mansion's network went dark during the lockdown, so that address no longer resolves. Fortunately, the house takes a snapshot of its own portal every night, and we recovered the most recent one and put it back online.

This task has one download:

- `invitation.png`, the scanned invitation

The recovered portal snapshot is online at:

- https://blackthorn-portal.vercel.app/

The portal's front page is not in a talkative mood. The invitation knows a better way in.

A few pointers:

- Decode the QR code to see where it sent the guests. The address will not load as written, but the same path works on the recovered copy of the portal.
- Hosts rarely say everything out loud. Read what the page says, then read what it is made of.
- Compare the page against the paper. Paper does not update itself.
